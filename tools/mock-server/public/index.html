On RF / signal quality: SystemAPI v1.8 exposes no RF endpoints — no frequency, RF level, antenna or ShowLink status for any device. The closest real signal is per-channel audio activity (LOW / GOOD / CLIPPING), which the server pushes every 5 seconds; that is simulated here. Battery level, battery health and cycle count are real API features and are fully simulated.
